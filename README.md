# Portfolio

Internal tools and systems I've built, with live demos on made-up data.

Live site: GitHub Pages from the `main` branch root.

- `index.html`: landing page and build register (edit the `BUILDS` list to add one)
- `demos/<name>/`: one folder per demo, each self-contained with its own `data/`

## Rule
Demos use fake customers, sites, people and prices. No employer name, branding, internal list or flow names, or real data. Each new build gets a demo added here.
