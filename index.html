How I build

Rules learnt the hard way, written down so every new build starts from them.

Inform, never block

Checks show up as warnings; the person doing the work decides. Hard lockouts over typos are what made the old systems hated.

No silent failures

Every hand-off that matters is locked and polled until it's confirmed. Nobody walks away thinking a quote was filed when it wasn't.

Works offline, installs nothing

Locked-down work PCs can't install software, so the tools are single HTML files that open from a synced folder.

Useful before mandatory

Adoption is won by being better than the spreadsheet. Analytics stay off the daily screens so nobody feels watched.

All demos use made-up customers, sites, people and prices. No company data is published here.
